# AI Hospital

Modality-agnostic diagnostic platform that produces grounded, clinician-verifiable reports.

## Highlights
- Supports 8 modalities: X-ray, CBCT, CT, MRI, Ultrasound, PET-CT, mammography, angiography
- Every report statement is linked back to the image region that produced it
- Unified detection → segmentation → report pipeline

## Tech Stack
YOLO · U-Net · Large Language Models
